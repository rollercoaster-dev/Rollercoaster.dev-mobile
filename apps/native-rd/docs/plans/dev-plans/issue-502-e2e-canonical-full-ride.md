## Context

### What the redesign actually removed (and what it did not)

The issue's premise is right about the _selectors_ and partly wrong about the _files_. Verified:

- **Genuinely deleted**: `BadgeEarnedModal` — zero hits for `BadgeEarnedModal` / `badge-earned` in `src/`. Its role is now `FinishRevealStage` (`src/components/FinishRevealStage/FinishRevealStage.tsx:86,132`).
- **Genuinely gone as identifiers**: `tab-fab-new-goal` (`src/navigation/FocusPillTabBar.tsx:34` has exactly 3 slots, no FAB), `new-goal-title`, `create-goal`, `start-working`, `completion-note-input`, `completion-save-note-button`, `badge-earned-image` — all zero source hits.
- **Deleted by #455** (`586ef92`, was "orphaned, not deleted" in the pre-rebase draft): `EvidenceDrawer`, `MiniTimeline`, `FABMenu`, `ProgressDots`, `CardCarousel`, `EvidenceItem` — component, styles, stories, tests and index all gone, and their i18n keys (`common:evidenceDrawer.*`, `common:timeline.*` → `Add evidence`, `Toggle evidence drawer`, `Tap to expand timeline`, plus `timelineJourney:step.noEvidence`) removed from `en` / `de` / `pseudo`. `EvidenceItemData` was relocated to `src/types/evidence.ts` in the same sweep. This closes Risk 8 outright. **The verification trap it used to illustrate still stands in general** — a live locale key is not proof a selector is live, since the component that consumed it may be unmounted — but it no longer has a live example in this repo, so the `evidence-viewer.yaml` taps at `:75-108` are now doubly dead: no component _and_ no key.
- **Rebuilt, not removed**: `CompletionFlow` is still a routed modal (`src/navigation/GoalsStack.tsx:36`) but is now a 4-stage machine `celebrate → design → baking → reveal` (`src/screens/CompletionFlowScreen/CompletionFlowScreen.tsx:58,92`). `NewGoalScreen` is now a 4-step wizard. `EditModeScreen` renders `EditGoalView`, and `StepList` (which still owns `step-list-new-step-input`, `src/components/StepList/StepList.tsx:1060`) has **no runtime render site** — only its own test file and `src/__tests__/accessibility.test.tsx`.
- **Registered but unreachable**: `BadgeDesignerScreen` is a `Stack.Screen` in both `GoalsStack.tsx:59` and `BadgesStack.tsx:18`, but **nothing calls `navigate("BadgeDesigner", …)`** anywhere in `src/`. `use-this-design` (`src/screens/BadgeDesignerScreen/BadgeDesignerScreen.tsx:830`) therefore resolves in source and is dead at runtime. `src/components/FinishDesignStage/FinishDesignStage.tsx:122` records that "the old pre-bake detour into BadgeDesignerScreen is gone, #449 D2".

### Why the current suite is worse than useless

`scripts/run-e2e.sh:30` runs `maestro test e2e/flows/` unfiltered, and `run-e2e.sh:5-8` **exits 0 when Maestro is absent** — a missing CLI reports success. `<repo-root>/turbo.json`'s `test:e2e` task is `cache: true` with `outputs: ["coverage/**"]` (which Maestro never writes), so the root alias can replay a FULL-TURBO green having launched nothing. The `# Status: required|optional` convention documented at `e2e/README.md:50-62` is parsed by nothing; `badge-redesign.yaml:4` doesn't even use the vocabulary (`# Status: TDD-style`) and `evidence-viewer.yaml` has no header at all. Isolation is inconsistent in four different idioms, and `settings-theme-switch.yaml:6` has a bare `launchApp` that only passes because alphabetical ordering puts `settings-theme-persists-restart.yaml` (which sets and persists Night Ride) immediately before it — its "real outcome assertion" is void in suite runs, a coupling `badge-view.yaml:9-14` documents in prose.

### What the canonical ride proves

One self-contained flow that a human can watch once and believe the redesign works end to end: a goal created through the 4-step wizard with a **two-type** evidence plan, its steps **reordered and reparented through the only non-drag path**, **every planned type captured**, completion **auto-advancing** past a **set-aside** step, the Timeline handing off to the **exact** Focus step (paused _and_ completed variants), a **step reopen**, and a bake that lands on **Badge Detail with a real signed PNG** and a populated **Badges wall**.
