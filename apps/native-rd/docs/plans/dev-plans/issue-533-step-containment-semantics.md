# Development Plan: Issue #533

## Issue Summary

**Title**: [Research] Parent ↔ sub-step semantics: a parent step is completable with every child unfinished
**Type**: research (no production code changes)
**Complexity**: SMALL (research/doc issue — sized by doc effort, not LOC)
**Estimated Lines**: ~500-650 (research doc) + 1 index row + 4 follow-up issue bodies (not repo LOC)

This plan governs **writing the research doc**, not implementing anything it recommends. Deliverable: `apps/native-rd/docs/research/step-containment-semantics.md`, an `index.md` row, and sequenced follow-up issues.

**Framing note (supersedes the issue's own framing).** The issue asks whether ADR-0010's "never refuse an action" bars a parent-completion gate — i.e. it poses the question as ADR adjudication. Session review on 2026-07-30 established that the mechanics answer it first, and more cheaply: nothing in this app gates completion on structure at _any_ container level, and a gate is not implementable as an invariant here regardless of what the ADRs say (D2). The doc argues from mechanics and cites the ADRs as corroboration, not as the deciding authority. Two of the issue's five headline unknowns dissolve entirely (D8, D9) and a sixth finding the issue never names becomes the substantive one (D6, F6).
